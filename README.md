# Frontend Version Control Task

Practice repository for demonstrating Git and GitHub workflows: branching, commits, pull requests, merging, reverting and renaming branches.

Branch Name and Purpose

main

Contains the main and stable version of the project.

feature-header

Used to create and modify the website header.

feature-footer

Used to create and modify the website footer.

Lessons learned:
Through this exercise, I learned how to:

Create separate branches for different website features.

Make changes without directly affecting the main branch.

Commit and push changes to GitHub.

Create pull requests to propose changes.

Review and merge pull requests into the main branch.

Use Git commands to manage project changes.

Keep a project organized by working on individual features in separate branches.
